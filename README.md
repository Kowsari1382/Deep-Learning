## 📖 About
This repository contains practical implementations and educational notebooks focused on building and training Neural Networks from the ground up (or using standard frameworks). The primary focus is on solving core machine learning tasks: **Regression** (predicting continuous values) and **Classification** (categorizing data into discrete classes).

---

## ✨ Features
- 📈 **Regression Implementation**: Training and evaluating regression models (e.g., Linear/Logistic Regression) using neural network architectures (`lr.ipynb`).
- 🎯 **Classification Implementation**: Building and optimizing multi-class or binary classification models with custom or standard neural networks (`classification.ipynb`).
- 📊 **Evaluation & Visualization**: Includes metrics evaluation and plotting of training dynamics (Loss/Accuracy curves).
- 🧹 **Clean & Documented Code**: Well-commented Jupyter Notebooks to help understand forward passes, gradient computation, and optimization steps.

## ⚙️ Prerequisites & Installation
To run these notebooks, you need **Python 3.8** or higher and **Jupyter Notebook** installed. 

Common required libraries include:
- `numpy`
- `pandas`
- `matplotlib` / `seaborn`
- `scikit-learn`
- `torch` or `tensorflow` *(depending on the specific implementation in the notebooks)*

You can install the basic dependencies via pip:
```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```
*(Note: If the notebooks use PyTorch or TensorFlow, please install them according to the official documentation.)*

## 🚀 Usage
1. **Clone the repository**:
```bash
   git clone https://github.com/Kowsari1382/Deep-Learning.git
```
2. **Navigate to the project directory**:
```bash
   cd Deep-Learning
```
3. **Start Jupyter Notebook**:
```bash
   jupyter notebook
```
4. Open either `lr.ipynb` or `classification.ipynb` in your browser and run the cells sequentially to train the models and view the results.
